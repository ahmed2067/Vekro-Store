# VEKRO STORE

متجر عربي RTL مبني باستخدام Node.js 20+ وExpress، مع تخزين المنتجات والطلبات في Supabase PostgreSQL.

## المزايا الموجودة في الكود
- واجهة متجر متجاوبة مع البحث والتصنيفات والسلة.
- تسجيل طلبات الدفع عند الاستلام في قاعدة بيانات Supabase.
- رقم طلب فريد وتتبع الطلب باستخدام رقم الطلب ورقم الهاتف.
- لوحة إدارة على المسار `/admin` لتسجيل دخول المدير وإدارة المنتجات المحلية وتغيير حالة الطلبات.
- استيراد منتجات Safka من خلال وسيط خادمي عند ضبط المسار والمفتاح الصحيحين.

## متغيرات البيئة المطلوبة
اضبطها في إعدادات الاستضافة، ولا تضع القيم السرية في GitHub أو ملفات الواجهة:
- `DATABASE_URL`: رابط اتصال PostgreSQL من Supabase (يفضّل Transaction Pooler للخوادم ذات الاتصالات القصيرة أو المتقطعة).
- `SESSION_SECRET`: قيمة عشوائية طويلة لا تقل عن 32 حرفًا.
- `ADMIN_EMAIL`: بريد المدير.
- `ADMIN_PASSWORD`: كلمة مرور قوية وفريدة.
- `NODE_ENV=production`.
- إعدادات Safka اختيارية: `SAFKA_API_BASE_URL`, `SAFKA_API_KEY`, `SAFKA_PRODUCTS_PATH`.

## تشغيل محلي
1. ثبّت Node.js 20 أو أحدث.
2. نفّذ `npm install`.
3. انسخ `.env.example` إلى `.env` وأدخل القيم محليًا.
4. نفّذ `npm start`.
5. افتح `/admin` للدخول إلى لوحة الإدارة.

## قاعدة البيانات
تم إعداد الجداول `public.vekro_products` و`public.vekro_orders` في Supabase مع تفعيل Row Level Security ومنع وصول أدوار anon وauthenticated مباشرة. يتصل خادم Node.js بقاعدة البيانات من جهة الخادم باستخدام `DATABASE_URL`.

رابط مشروع Supabase: https://supabase.com/dashboard/project/olihhooalqfyusubccpr

## Safka
اضبط متغيرات Safka من وثائق حسابك الرسمية. لا تضع المفتاح في HTML أو JavaScript للمتصفح. لم يتم تفعيل إنشاء طلبات داخل Safka لأن مسار الإنشاء وبنية الطلب لم يتم التحقق منهما بعد.

التوثيق: https://public-api-docs.safka-eg.com/

## ملاحظات قبل الإطلاق العام
- لوحة الإدارة تستخدم جلسات في ذاكرة الخادم؛ ستنتهي الجلسات عند إعادة تشغيل الخدمة، ويلزم تحسين تخزين الجلسات قبل التوسع.
- حسابات العملاء وإنشاء حساب/تسجيل دخول العملاء غير مفعّلة في هذه النسخة.
- يجب اختبار الحماية، النسخ الاحتياطي، الأسعار والمخزون، ورسائل التأكيد قبل استقبال طلبات حقيقية.
- الدفع حاليًا عند الاستلام فقط، ولا توجد بوابة دفع إلكتروني مفعّلة.
- لم يتم ربط إنشاء الطلبات في Safka بعد؛ تسجيل الطلب الحالي في قاعدة بيانات المتجر فقط.

## النشر
يلزم إعداد `DATABASE_URL` وباقي أسرار الخادم في إعدادات الاستضافة قبل اعتبار المتجر جاهزًا. لا ترفع أي مفاتيح أو كلمات مرور إلى GitHub.
